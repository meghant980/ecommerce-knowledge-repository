# Functional Requirements

Introduction

Functional requirements describe the functions and services that the
e-commerce business system must provide to its users.

 1. User Registration and Login

The system shall allow customers and sellers to create accounts.

The system shall:

- Register new users.
- Authenticate users using login credentials.
- Allow users to update their profile information.
- Allow users to reset forgotten passwords.

2. Product Management

The system shall allow sellers and administrators to manage products.

The system shall:

- Add new products.
- Update product details.
- Remove products.
- Display product information.
- Categorize products.
- Manage product prices and availability.

 3. Product Search

Customers shall be able to search for products.

The system shall support:

- Keyword-based search.
- Product category filtering.
- Price filtering.
- Sorting by price or relevance.

4. Shopping Cart

Customers shall be able to manage products in their shopping cart.

The system shall:

- Add products to the cart.
- Remove products from the cart.
- Update product quantities.
- Calculate the total order amount.

5. Order Management

The system shall allow customers to place and manage orders.

The system shall:

- Create orders after checkout.
- Generate an order ID.
- Display order details.
- Allow customers to track order status.
- Allow eligible orders to be cancelled.

 6. Payment Processing

The system shall support online payment processing.

The system shall:

- Display the total payable amount.
- Process customer payments through a payment service.
- Verify payment status.
- Generate transaction information.
- Handle failed payments.

7. Inventory Management

The system shall maintain product inventory.

The system shall:

- Track available stock.
- Update stock after an order.
- Indicate unavailable products.
- Allow sellers to update inventory.
 8. Delivery Management

The system shall support order delivery.

The system shall:

- Assign orders for delivery.
- Store delivery information.
- Update delivery status.
- Confirm successful delivery.
 9. Return and Refund

The system shall support eligible product returns.

The system shall:

- Allow customers to request returns.
- Record return requests.
- Track return status.
- Process eligible refunds.

10. Reviews and Ratings

Customers shall be able to provide feedback.

The system shall:

- Allow customers to rate products.
- Allow customers to submit reviews.
- Display product ratings and reviews.

 11. Notifications

The system shall provide notifications for important events such as:

- Order confirmation
- Payment confirmation
- Order shipment
- Delivery
- Cancellation
- Return and refund updates
